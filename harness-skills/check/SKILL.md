# 검산 — 특이사항 카드를 믿기 전에 다시 확인

notes/ISSUES.md는 다른 AI가 작성했다고 생각하고, 카드에 적힌 말을 그대로 믿지 말고 원본에서 다시 확인해라. 이 스킬은 앞선 대화를 모르는 새 Codex 세션에서 실행하는 것이 좋다. 만약 이번 대화 안에서 네가 notes/ISSUES.md를 만들었거나 고쳤다면 첫 줄 끝에 「같은 세션」이라고 적어라.

첫 줄: [시각] 카드 N장 — ✅ a장 / ❌ b장 / 원인 [추측] c개

## 카드마다 쓸 모양

```
## I-1 <카드 제목> — ✅ 또는 ❌
- 다시 센 결과: 카드 숫자 vs 다시 센 숫자 (쓴 방법 한 줄)
- 원본 그대로: 카드가 가리킨 줄 2~3개(파일:줄)
- 원인 점검: [근거 확인] 어디서 확인했는지 / 또는 [추측]
- 빠진 경우: 같은 기준인데 카드에 없는 경우
```

- 다시 셀 때는 카드를 만들 때와 다른 방법(다른 명령어, 다른 열 조합 등)을 써라.
- 원본 줄은 고치지 말고 파일에 있는 그대로 보여 줘라.
- 「왜 생긴 것 같나」가 README·데이터에서 확인되면 [근거 확인]과 확인한 곳을 적고, 확인할 수 없으면 [추측]을 적어라.

## 맨 아래에 쓸 것
- 카드에 없는 특이사항: 결과 숫자를 바꿀 만한데 어느 카드에도 없는 것이 보이면 issues 스킬의 카드 모양(본 것 · 왜 생긴 것 같나 · 정해야 할 것 · 왜 물어야 하나 · 상태)으로 적고, 번호는 C-1, C-2 … 로 붙여라. 없으면 「찾지 못함」과 어디까지 확인했는지를 적어라.
- 마지막 줄: 이 검산은 카드에 적힌 사실(숫자·줄·근거)이 맞는지만 본다. 어떤 기준이 옳은지는 담당자 답으로 정해진다.

## 하지 말 것
- notes/ISSUES.md를 직접 고치지 마라. 틀린 곳은 notes/CHECK.md에만 적고, 고칠지는 내가 정한다.
- 기준을 정하거나 코드·데이터를 바꾸지 마라.
