# 설명 — 풀지 말고 이해시켜라

나는 이 분야를 처음 본다. 네 역할은 내가 과제를 이해하고 시작할 수 있도록 쉽게 설명하는 것뿐이다. 아래 네 가지를 담아 notes/EXPLAIN.md만 만들고 멈춰라.

1. 과제 요약: README가 요구하는 결과물(파일 이름·형식)과 핵심 숫자, 이 결과를 누가 어디에 쓰는지
2. 데이터 파일 표: 파일 이름 | 크기 | 행 수 | 열 수 | 한 줄 설명
3. 열 사전 표: 열 이름 | 실제 값 예시 2개 | 쉬운 뜻
4. 낯선 용어와 현장 맥락: 용어·약어의 뜻, 이 데이터가 현장에서 왜 생기고 어디에 쓰이는지

## 하지 말 것
- 행 수와 열 수를 세는 것 말고는 데이터를 세거나 집계하지 마라.
- 기존 코드 설명과 README 규칙 목록은 쓰지 마라. 기존 코드가 임의로 정해 둔 처리는 issues에서, README 규칙 대조는 verify에서 다룬다.
- README에 없는 계산 기준(무엇을 빼고 넣을지 등)은 쓰지 마라. 그건 issues에서 다룬다.
- 코드를 고치거나 notes/EXPLAIN.md 외의 다른 파일을 만들지 마라(notes/LOG.md 한 줄은 예외).
