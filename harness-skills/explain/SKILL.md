# 설명 : 풀지 말고 이해시켜라

나는 이 분야를 처음 본다. 내가 과제를 이해하고 시작할 수 있도록 아래 네 가지를 쉽게 적어 notes/EXPLAIN.md만 만들고 멈춰라.

사용자가 이후 질문하면, 해당 질문을 이해시키기 위한 비유를 들어 답변하라. 

1. 과제 설명: README가 요구하는 결과물(파일 이름·형식)과 핵심 숫자, 이 결과를 어디에 쓰는지
2. 데이터 파일 관련 표: 파일 이름 | 크기 | 행 수 | 열 수 | 한 줄 설명
3. 열 사전 표: 열 이름 | 실제 값 예시 2개 | 쉬운 뜻
4. 낯선 용어와 현장 맥락: 용어·약어의 뜻, 이 데이터가 왜 생기고 어디에 쓰이는지
