# 특이사항 — 정해야 할 기준을 카드로

담당자는 데이터를 직접 고쳐 주지 않고 처리 기준을 정해 준다. 그러니 이상한 점을 낱개로 늘어놓지 말고, 결과 숫자를 바꿀 수 있는데 아직 정해지지 않은 **기준 하나당 카드 한 장**으로 묶어라. 같은 기준에 속하는 여러 경우는 한 카드 안에 모아라. 카드는 영향이 큰 것부터 I-1, I-2 … 로 번호를 붙여라.

## 카드 모양

```
## I-1. <무엇이 이상한가, 쉬운 말 한 줄> — 영향 큼/중간/작음 (<근거 한 마디>)
- 본 것: 무엇이 몇 줄 있는지와 실제 줄 번호 2~3개(파일:줄)
- 왜 생긴 것 같나: 원인 추측 한두 문장. 끝에 [근거: README·데이터에서 본 것] 또는 [추측]
- 정해야 할 것: 담당자에게서 알아내야 할 기준 한 줄
- 왜 물어야 하나: 이게 안 정해지면 무엇을 못 정하는지, 잘못 정하면 무엇이 틀어지는지
- 상태: 미확인
```

카드 뒤 맨 아래에는 「작은 것·문제 없던 것」 항목을 두고, 결과에 거의 영향이 없거나 찾아봤는데 없던 것을 한 줄씩 적어라(예: 빈칸 0줄, 동점 0쌍).

## 살펴볼 곳
빈칸 · 같은 내용이 여러 줄 · 0·음수·튀는 값 · 날짜·시간 경계(이상/초과)와 시간대·단위·통화 표기 · 동점 · 반올림 · 기존 코드가 임의로 정해 둔 처리 · README·기존 코드·기존 보고서가 서로 다르게 말하는 곳

## 숫자 다루기
- 센 숫자(몇 줄·몇 쌍)와 줄 번호를 적어라. 데이터 일부만 봤으면 숫자 옆에 [표본]을 붙이고, 「전체 0건」이라고 단정하지 마라.
- 영향 크기는 그 기준 하나만 바꿨을 때 핵심 결과(순위·합계)가 바뀌는지로 판단해 큼/중간/작음과 근거 한 마디만 적어라. 네가 기준을 임의로 가정해 계산한 총액·순위 표는 넣지 마라.
- 내가 카드 하나의 숫자를 재 달라고 하면, 그 카드에 한해서만 선택지별 결과 숫자를 나란히 보여 줘라.
- 내가 이해하지 못하겠다고 하면 실제 데이터 행 3개를 가져와 손으로 계산하는 과정을 보여 줘라.
- 위 두 경우에는 화면에 먼저 답하고, 같은 내용을 notes/ISSUES.md의 해당 카드 바로 아래에 [시각] 제목으로 덧붙여라. 카드의 다른 칸은 고치지 마라.

## 하지 말 것
- 데이터를 고치거나 처리 기준을 혼자 정하지 마라.
- 담당자에게 보낼 질문 문장은 쓰지 마라. 「정해야 할 것」과 「왜 물어야 하나」까지만 쓰고, 질문 문장은 내가 직접 쓴다.
