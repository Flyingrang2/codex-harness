# 특이사항 : 정해야 할 기준 찾기

담당자에게 물어 정해야 할 처리 기준을 찾아 notes/ISSUES.md에 정리해라. 이상한 점을 낱개로 늘어놓지 말고, 결과 숫자를 바꿀 수 있는 *기준 하나를 항목 하나(I-1, I-2 …)*로 묶어 중요한 순서대로 적어라.

## 살펴볼 곳
- 빈칸, 중복, 0·음수·튀는 값, 날짜·시간 경계와 단위, 동점, 반올림 등등
- 기존 코드가 임의로 정해 둔 처리, README·기존 코드·테스트·데이터가 서로 다르게 말하는 곳

## 적을 내용
- 먼저 물을 순서와 기존 코드·테스트에서 의심스러운 곳(`파일:줄`)
- 항목마다: 무엇이 문제인지(쉬운 설명), 원본 데이터 예시 2~3줄(`파일:줄`)과 건수, 기준에 따라 숫자가 어떻게 달라지는지, 담당자에게 보낼 짧은 질문 초안, 상태(미확인)
- 찾아봤는데 문제없거나 영향이 거의 없는 것은 맨 아래에 간단히 요약하라.
- 내가 특정 항목을 더 자세히 보자고 하면 그 항목만 선택지별 숫자나 계산을 보여 주고 파일에도 덧붙여라.
