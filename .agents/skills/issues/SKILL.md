# 특이사항 — 사실만 확인하고, 무엇을 물을지는 내가 정한다

데이터·README·기존 코드에서 계산 실수를 부르거나 결과 숫자를 바꿀 만한 요소를 찾아 notes/ISSUES.md에 아래 표로 정리해라.

| 무엇 | 몇 행 | 실제 예시(최대 3개) | 결과 숫자에 주는 영향 |

- 결과 숫자에 주는 영향: 해당 데이터를 포함할 때와 뺄 때(또는 A안 vs B안) 핵심 결과 숫자가 어떻게 달라지는지 나란히 적어라.
- 살펴볼 곳: 빈칸 · 같은 ID가 여러 줄 · 0·음수·튀는 값 · 날짜·시간 경계(이상/초과)와 시간대·단위 표기 · 동점 · 반올림 · README·기존 코드·기존 보고서가 서로 다르게 말하는 곳
- 내가 특정 조건 하나만 확인해 달라고 하면 그것만 세어서 같은 표 형식으로 답해라.
- 내가 이해하지 못하겠다고 하면 실제 데이터 행 3개를 가져와 손으로 계산하는 과정을 보여 줘라.

## 하지 말 것
- 데이터 일부만 보고 「전체 0건」이라고 단정하지 마라. 표본만 확인했으면 숫자 옆에 [표본]을 붙여라.
- 데이터를 고치거나 처리 기준을 혼자 정하지 마라.
- 담당자에게 보낼 질문 문장을 대신 작성하지 마라.
